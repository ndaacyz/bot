## spek minimal

| Requirement | Versi Minimum | Keterangan |
|-------------|---------------|------------|
| Node.js | v18.0.0 | [Download di sini](https://nodejs.org/) |
| NPM | v9.0.0 | Terinstall otomatis bersama Node.js |
| WhatsApp | - | Akun WhatsApp buat botnya |

Install:
```bash
apt update && apt upgrade -y
apt install nodejs npm git -y
git clone https://github.com/ndaacyz/bot
cd bot
npm i
npm start
